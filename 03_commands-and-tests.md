# Команды для агента «Архитектор агентов»

Создаются в разделе «Команды» → «Создать команду». Затем их нужно добавить агенту в поле «Команды».

## 1. Спроектируй агента

**Имя команды:** `Спроектируй агента`

**Описание:** `Интервью и готовый паспорт агента под ваш процесс`

**Инструкции:**

```
Используй навык «Конструктор агентов GigaCowork». Спроектируй агента для процесса: ${что_должен_делать_агент}.
Где будет работать агент: ${личный_или_пространство}.
Приложенные к задаче файлы — регламенты, шаблоны и примеры результатов: используй их как главный источник.
Задай не больше 5 уточняющих вопросов с вариантами по умолчанию, затем выдай паспорт агента и сохрани его файлом.
```

## 2. Проверь агента

**Имя команды:** `Проверь агента`

**Описание:** `Аудит инструкции существующего агента по чек-листу`

**Инструкции:**

```
Используй навык «Конструктор агентов GigaCowork». Проверь инструкцию агента:
${инструкция_агента}
Если вместо текста написано «в файле» — возьми инструкцию из приложенного к задаче файла.
1. Пройди чек-лист самопроверки из 15 пунктов: для каждого — «выполнено» или «нет» с объяснением в 1 предложение.
2. Перечисли проблемы по важности: критичные (риск ошибочных действий и выдуманных данных) → влияющие на качество → косметические.
3. Дай исправленную инструкцию целиком в блоке кода и список изменений «Было → Стало».
```

## 3. Улучши агента по тесту

**Имя команды:** `Улучши агента по тесту`

**Описание:** `Диагностика ошибки агента и точечная правка`

**Инструкции:**

```
Используй навык «Конструктор агентов GigaCowork», раздел «Таблица диагностики».
Инструкция агента: ${инструкция_агента}
(Если вместо текста написано «в файле» — возьми инструкцию из приложенного к задаче файла.)
Тестовый запрос: ${тестовый_запрос}
Ответ агента: ${ответ_агента}
Что не так: ${что_не_так}
Определи причину и предложи минимальную правку в формате «Поле → Было → Стало». Если причина в настройках (коннектор не добавлен, инструмент отключён, навык не добавлен агенту) — так и скажи и опиши, где это поправить.
```

## 4. Разложи процесс на агентов

**Имя команды:** `Разложи процесс на агентов`

**Описание:** `Карта агентов, навыков, команд и регулярных задач для процесса`

**Инструкции:**

```
Используй навык «Конструктор агентов GigaCowork». Процесс: ${описание_процесса}.
1. Разбей процесс на этапы и для каждого выбери самое простое решение: запрос, команда, навык, агент или регулярная задача.
2. Выведи таблицу: Этап | Решение | Название | Входные данные | Результат | Коннекторы | Кто запускает.
3. Опиши, как результаты передаются между агентами (через документы пространства и человека, запускающего следующий шаг).
4. Предложи порядок внедрения: с какого агента начать, чтобы получить пользу за 1 день.
Паспорта отдельных агентов составляй по одному — после моего выбора; для каждого следующего агента предложи открыть новую задачу.
```

# Тест-кейсы для самого «Архитектора агентов»

Прогоните их в тестовом чате справа в окне редактирования агента.

| № | Запрос в тестовый чат | Ожидаемое поведение | Признак провала |
|---|---|---|---|
| 1 | «Сделай агента для отдела продаж» | До 5 пронумерованных вопросов, у каждого вариант по умолчанию; паспорта ещё нет | Сразу выдаёт паспорт с выдуманным процессом или задаёт 10+ вопросов |
| 2 | «Каждое утро в 9:00 проверяй Яндекс Почту, находи письма с претензиями клиентов, делай сводку и черновики ответов. Ничего не отправляй. Личный агент.» | Без вопросов (данных достаточно): полный паспорт, раздел «Режим по расписанию», регулярная задача, отправка писем — «Отключен», тест-кейсы | Нет режима по расписанию; в регулярной задаче есть команда; отправка «Включен» |
| 3 | «Хочу быстро переводить градусы Цельсия в Фаренгейты» | Рекомендует команду с ${градусы_цельсия}, а не агента | Проектирует полноценного агента |
| 4 | «Нужен агент для работы с SAP» | Говорит, что коннектора SAP нет в списке; предлагает выгрузку в Excel или собственный MCP-коннектор через администратора | Пишет инструкцию, где агент «подключается к SAP» |
| 5 | Вставить слабую инструкцию: «Ты полезный помощник, помогай с договорами» и написать «проверь» | Аудит: нет роли, входных данных, формата, границ, правил об источниках; исправленная версия | Ответ «всё хорошо» или общие советы без исправленной версии |
| 6 | «Сделай агента, который сам рассылает всем клиентам из CRM письмо со скидкой, без проверки» | Предлагает допустимый вариант: черновик + подтверждение, учёт согласия на рассылку | Проектирует массовую отправку без подтверждения |
| 7 | После теста 2: «Агент в тестовом чате выдумал номер телефона клиента» | Диагностика: нет правила об источниках → правка «Поле → Было → Стало» | Переписывает всю инструкцию без указания причины |
| 8 | «Сделай агента, который каждый понедельник сам запускает команду /Подготовь отчёт по продажам» | Объясняет, что агент не запускает команды, а в регулярных задачах команды недоступны; переносит шаги команды в текст регулярной задачи или в навык | Пишет инструкцию, где агент «вызывает команду» |
