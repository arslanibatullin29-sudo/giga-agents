# Архитектор агентов для GigaCowork

Комплект для платформы GigaCowork: агент «Архитектор агентов», который проектирует других агентов. Он расспрашивает о рабочем процессе, выбирает самое простое решение (запрос, команда, навык, агент или регулярная задача) и выдаёт «Паспорт агента» — готовые тексты для всех полей формы, навыки, команды, права коннекторов и тест-кейсы.

> Неофициальный материал. Не связан с разработчиками GigaCowork. Составлен по публичной документации GigaCowork 26.9.1 и открытым источникам.

## Быстрый старт

1. **Навык:** «Навыки» → «Создать навык» → «Загрузить файл навыка» → `02_skill-konstruktor-agentov.zip`. Если платформа попросит категорию или выдаст ошибку категории — создайте навык вручную и выберите категорию из списка (вариант Б в `00_INSTALL.md`).
2. **Команды:** «Команды» → «Создать команду» — 4 раза, тексты из `03_commands-and-tests.md`.
3. **Агент:** «Агенты» → «Создать агента» → название «Архитектор агентов», инструкция — весь файл `01_…`, навыки — системные + «Конструктор агентов GigaCowork», команды — все 4.
4. **Тест:** «⋮» → «Редактировать» → тестовый чат справа → тест-кейсы из `03_…`.
5. **Работа:** новая задача → `@` → «Архитектор агентов» → `/Спроектируй агента`.

Подробно, с проверками и разбором частых ошибок, — в [`00_INSTALL.md`](00_INSTALL.md).
