# Архитектор агентов для GigaCowork

Агент для платформы GigaCowork, который проектирует других агентов. Он проводит интервью по рабочему процессу, выбирает самое простое решение (запрос, команда, навык, агент или регулярная задача) и выдаёт готовый к установке комплект: паспорт агента-оркестратора, навыки в стандарте платформы (с архивами для загрузки), команды, режимы инструментов коннекторов и тест-кейсы.

> Неофициальный материал, не связан с разработчиками GigaCowork. Составлен по публичной документации GigaCowork 26.9.1, устройству действующих навыков платформы и открытым источникам.

## Как устроен

| Фаза | Навык | Результат |
|---|---|---|
| Бриф | Интервью и выбор архитектуры агента | Бриф процесса и решение об архитектуре |
| Проект | Сборка паспорта агента | Тексты для формы агента, карта навыков, команды, коннекторы, регулярная задача, тесты |
| Навыки | Проектирование навыка GigaCowork | SKILL.md + «Референсы/» + архив для загрузки через `python_run` |
| Доработка | Аудит и доработка агента | Оценка по чек-листу и правки «Поле → Было → Стало» |

## Быстрый старт

1. **Навыки:** «Навыки» → «Создать навык» → «Загрузить файл навыка» → по очереди 4 архива из `02_skills/`.
2. **Команды:** «Команды» → «Создать команду» — 4 раза, по таблице из `03_commands-and-tests.md`.
3. **Агент:** «Агенты» → «Создать агента» → инструкция — `01_agent-instruction.md`, навыки — 4 новых + системные, команды — 4.
4. **Тест:** «⋮» → «Редактировать» → тестовый чат → 10 тест-кейсов.
5. **Работа:** новая задача → `@` → «Архитектор агентов» → `/Спроектировать агента`.

Подробно — в [`00_INSTALL.md`](00_INSTALL.md). Скачать всё: **Code → Download ZIP**.
