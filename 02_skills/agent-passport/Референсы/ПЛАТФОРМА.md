# Справочник: платформа GigaCowork

Сведено из документации GigaCowork 26.9.1 и устройства действующих навыков и агентов. Пометка «(наблюдение)» — видно в работающих навыках, но не описано в документации: перед тем как на это опираться, проверьте в своей версии.

## Задачи
- Задача — чат с изолированным контекстом; файлы одной задачи не видны в другой.
- Все запросы в задаче связаны: разные темы и разных агентов проектируют в разных задачах.
- При удалении задачи удаляются её файлы — паспорт нужно скачать или добавить в пространство.
- Промежуточные файлы задачи хранятся в `/session` (наблюдение).
- Многошаговую работу показывает компонент «Прогресс»; чек-лист шагов в навыке помогает его вести (наблюдение).

## Агенты
- Поля формы «Создать агента»: Название, Описание (видно в карточке), Инструкция, Навыки (по умолчанию — все системные), Команды, Коннекторы.
- Личному агенту доступны системные и личные навыки и команды; агенту пространства — системные и пространства.
- В окне редактирования справа — тестовый чат.
- Когда агент добавлен в задачу, в ней доступны только его навыки, команды и коннекторы.
- Агента добавляют кнопкой «Добавить агента» (`@`) или «Использовать» на карточке.
- Создание агента описано только через форму; навыки и команды можно создать из чата.
- Вызов одного агента другим не описан — связь агентов через документы пространства и человека.

## Навыки
- Файл SKILL.md: метаданные `category`, `version`, `name`, `description` (наблюдение; в документации поле категории названо `topic`).
- `category` — только значение из списка платформы, латиницей; иначе ошибка «Выберите категорию из списка». Подтверждённое значение — `sales`; остальные смотрите в выпадающем списке формы навыка.
- `description` («Когда применять») — по нему система решает, подключать ли навык.
- Ресурсы навыка — в папке `Референсы/`: методики, справочники, шаблоны, JSON-схемы, Python-код (наблюдение).
- Загрузка: «Навыки → Создать навык → Загрузить файл навыка» принимает `.md` (один файл) или `.zip` / папку (навык целиком). Имена файлов в архиве — с пометкой UTF-8, иначе русские имена искажаются.
- Навык, созданный в чате, — всегда личный; в пространство его копируют вручную. Копии не связаны с оригиналом.
- Системные навыки (наблюдение): «Работа с Excel (.xlsx)», «Работа с Word (.docx)», «Работа с PDF», «Работа с PowerPoint (.pptx)», «Полнотекстовый поиск», «Знания пространства», «Файлы воркспейса», «Инфографика».
- Python: код хранится файлом в `Референсы/`, агент читает его и передаёт в инструмент `python_run` (наблюдение). Поддерживается не весь Python: стандартные средства, без сети и установки пакетов.

## Команды
- Поля: Имя команды, Описание, Инструкции; аргументы `${имя}` показываются в поле «Аргументы».
- Вызов — через «/» в поле ввода. Агент сам команды не запускает.
- Для единообразных результатов в инструкции указывают формат и структуру результата.

## Коннекторы
- Права коннектора = права учётной записи пользователя.
- Режимы инструментов: «Включен», «Требует подтверждения», «Отключен». Настраиваются в разделе «Коннекторы» и действуют во всех задачах пользователя.
- Служебные инструменты подключения не отключают. Часть инструментов может выключить администратор; часть коннекторов уже авторизована администратором.
- MCP-коннекторы не предлагают авторизацию сами.
- Набор инструментов у коннекторов разный — сверяйте шаги с карточкой коннектора.
- Список: 1С, amoCRM, BotHelp, Calendly, Confluence, Email / Почта, Gmail, Google Calendar, Google Drive, iiko, InSales, Mail.ru, Microsoft Outlook, Mindbox, MTS Link, MPSTATS, RetailCRM, Saby CRM (СБИС), Skillaz, Telegram, UIS, Wazzup, YClients, Zoom, Битрикс24, Веб-поиск, Кайтен, Мессенджер МАКС, Мое дело, МойСклад, Планфакт, Почта России, ProgressMe, Хантфлоу, Юздеск, Яндекс Диск, Яндекс Почта; коннекторы партнёров; собственные MCP-коннекторы через администратора.

## Регулярные задачи
- Поля: Название, Запускать (каждый день / неделю / месяц + время), Задача, Повторять (всегда / до даты).
- «Каждый день» — у всех времён одинаковые минуты (9:15, 13:15, 18:15).
- Каждый запуск создаёт отдельную задачу в «Истории»; запустить вручную — «⋮ → Запустить задачу».
- Работают навыки пользователя и навыки агента, добавленного к задаче; коннекторы называют в тексте; команд нет; пользователя для вопросов нет.

## Пространства
- Общие документы доступны всем задачам пространства.
- Каждый участник видит свои задачи и использует свои коннекторы.
- Работают только навыки и агенты пространства; агента пространства создаёт и меняет только владелец.

## Плагины
- Готовые пакеты «агент + навыки + команды», публикует администратор.
- Плагин нельзя редактировать; некоторые компоненты (навыки) можно скопировать.
- Плагин может нести справочные данные в папке `Данные/`, доступные через «Файлы воркспейса» (наблюдение).

## Файлы
TXT, MD, DOCX, PDF с текстовым слоем, XLSX, XLSM, XLS, CSV, TSV, PARQUET, JSON, JSONL, PPTX, PNG, JPG, GIF, WEBP. Результат можно отдать файлом, диаграммой или холстом.

## Модель
Семейство GigaChat: структура на Markdown (без XML), конкретные числа вместо «несколько», пример ответа в инструкции, инструменты вызываются по одному.
