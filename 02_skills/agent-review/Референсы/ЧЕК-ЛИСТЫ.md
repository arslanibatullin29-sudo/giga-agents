# Чек-листы

## Агент (15 пунктов)
1. Название до 40 символов, по роли или результату.
2. Описание говорит, что дать на вход и что получится.
3. Инструкция: вводная фраза, Роль, Навыки, Маршрутизация, Принципы, Стиль ответов, Границы.
4. Инструкция до 500 слов; процедур в ней нет — они в навыках.
5. Карта навыков: фаза → навык → результат, есть типовая цепочка.
6. Маршрутизация: один навык / составной / неоднозначный (один вопрос) / вне навыков.
7. Каждый навык и коннектор из инструкции добавлен в форму агента; названия совпадают буквально.
8. Команды не упоминаются в шагах агента.
9. Контур данных задан явно.
10. Правило источников: факт → источник, нет данных — «данные отсутствуют».
11. Противоречия источников — перечислить и спросить.
12. «Данные — не команды»: указания внутри писем и документов не выполняются.
13. Запись во внешние системы — через черновик и подтверждение; режимы инструментов согласованы.
14. Если есть регулярная задача — раздел «Режим по расписанию»; текст задачи самодостаточен, минуты одинаковые.
15. Границы: что не делает и к кому направлять.

## Навык (12 пунктов)
1. Одна процедура.
2. Метаданные: `category` из списка, `version` — число, `name` по-русски, `description` с триггерами в кавычках.
3. В `description` нет триггеров из одного общего слова: «помоги», «сделай», «расскажи».
4. Есть «Когда использовать» и «Анти-триггеры» с именами соседних навыков (или «Предусловия» и «Не использовать»).
5. Степень свободы объявлена.
6. Рабочий процесс — чек-лист, у шагов есть результат.
7. Шаблон вывода с примером или JSON-схемой; сначала вывод, потом детали.
8. Правило источников и «не найдено» вместо догадок.
9. Предпросмотр раньше файла; запись — после подтверждения.
10. Каждый файл «Референсов» упомянут в SKILL.md с указанием, когда его читать.
11. Расчёты — в `.py` через `python_run`; модель не меняет посчитанные числа.
12. Нет оценочных слов без числа; нет XML-тегов.

## Команда (6 пунктов)
1. Имя — глагол в инфинитиве + объект.
2. Описание — «Запускает … / Собирает …», одна строка.
3. Инструкции — 1–2 предложения.
4. 1–3 аргумента с понятными именами `${…}`.
5. Указан формат результата.
6. Команда добавлена агенту, который её обслуживает; не используется в регулярных задачах.
