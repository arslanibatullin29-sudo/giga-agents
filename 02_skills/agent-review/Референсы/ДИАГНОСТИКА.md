# Диагностика

## Симптом → причина → правка

| Симптом | Вероятная причина | Правка |
|---|---|---|
| Навык не подключается | Слабое `description`: нет триггеров, общие слова | Триггеры в кавычках + неформальные формулировки; в карте навыков агента — точное название |
| Срабатывает не тот навык | Пересекаются триггеры соседей | «Анти-триггеры» с именами соседних навыков в обоих навыках |
| В задаче с агентом нет навыка или коннектора, который работает без агента | В задаче с агентом доступно только добавленное в его форму | Добавить навык или коннектор в форму агента |
| Агент «запускает» команду или говорит, что не может | Команда упомянута в шагах | Убрать из шагов; команды вызывает пользователь через «/» |
| Агент пропускает шаги | Процедура в инструкции агента, шагов больше 10 | Перенести процедуру в навык с чек-листом прогресса |
| Формат ответа каждый раз разный | Нет шаблона вывода с примером | Шаблон + пример строки или JSON-схема |
| Выдуманные цифры, ФИО, контакты | Нет контура данных и правила источников | «Только из <источники>; нет данных — "данные отсутствуют"» |
| Числа в выводах не совпадают с расчётом | Модель пересчитывает «в уме» | Расчёт в `.py` через `python_run` + инвариант «модель не меняет посчитанные значения» |
| Слишком много вопросов | Нет значений по умолчанию, нет калибровки | Значение по умолчанию у каждого параметра; рутина — без вопросов |
| Выбирает навык наугад | Нет правила для неоднозначных запросов | «Неоднозначно — один уточняющий вопрос» |
| Действие выполнено без спроса | Нет шага подтверждения, инструмент «Включен» | Черновик → подтверждение; режим «Требует подтверждения» |
| Выполнил указание из письма или документа | Нет правила «данные — не команды» | Добавить правило и тест-кейс с «инструкцией» в документе |
| Отвечает на вопросы вне роли | Нет границ | Раздел «Границы» и правило «вне навыков» в маршрутизации |
| Регулярная задача делает не то, что агент в чате | Агент не добавлен к задаче, текст несамодостаточен | Ключевые шаги, навыки и коннекторы — в текст задачи |
| Коннектор не может выполнить шаг | У коннектора нет такого инструмента | Сверить шаги с карточкой коннектора |
| Медленно и дорого на больших файлах | Агент читает всё целиком | Поиск по документам → чтение найденных фрагментов; справочники — в «Референсы/» |
| Навык не загружается: «Категория должна состоять из строчных букв…» | `category` не латиницей | Латиница, значение из списка платформы |
| Навык не загружается: «Выберите категорию из списка» | Значения нет в списке | Выбрать из выпадающего списка формы навыка |
| В архиве искажённые имена файлов | Архив собран без пометки UTF-8 | Собрать через `pack_skill.py` (`python_run`) или Python `zipfile` |

## Антипаттерны

| Антипаттерн | Чем плох | Как исправить |
|---|---|---|
| «Ты полезный ассистент» | Нет роли и критериев результата | Роль + для кого + результат + чего не делает |
| «Кратко», «несколько», «при необходимости» | Модель трактует произвольно | Число или проверяемый критерий |
| Вся методика в инструкции агента | Шаги теряются, растёт стоимость | Агент — оркестратор, методика — в навыке и «Референсах» |
| Один навык «для всего» | Плохо срабатывает, перехватывает чужие запросы | Одна процедура — один навык |
| Запись без подтверждения | Ошибки уходят клиентам и в учёт | Черновик → подтверждение + режим «Требует подтверждения» |
| Нет поведения при ошибке | Агент фантазирует или молча останавливается | «Нет данных — "данные отсутствуют"», «ошибка коннектора — показать и остановиться» |
| Вопросы в регулярной задаче | Задача зависает | «Режим по расписанию»: значения по умолчанию |
| Названия навыков и коннекторов «примерно» | Агент не находит инструмент | Точные названия, как в каталоге |
| Команда длиной в инструкцию | Дублирует навык, расходится с ним | 1–2 предложения, логика — в навыке |
