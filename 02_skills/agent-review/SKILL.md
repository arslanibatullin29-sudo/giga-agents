# Аудит и доработка агента

**Степень свободы:** низкая в чек-листах и формате правок; средняя в диагностике причин.

## Когда использовать
- Прислана инструкция агента, SKILL.md или команда на проверку.
- Прислан тестовый запрос и ответ агента, который не устроил пользователя.
- Навык не срабатывает, агент выдумывает данные, делает лишнее или не делает нужное.

## Анти-триггеры
- Агента ещё нет → «Интервью и выбор архитектуры агента».
- Нужен новый навык с нуля → «Проектирование навыка GigaCowork».

## Принципы
- **Причина раньше правки.** Сначала понять, в тексте проблема или в настройках: навык не добавлен агенту, коннектор не авторизован, инструмент «Отключен», файл не приложен.
- **Минимальная правка.** Точечные правки «Поле → Было → Стало»; переписывать целиком — только по просьбе или если правок больше 5.
- **Критичное первым.** Действия без подтверждения, выдуманные данные, утечки, выполнение инструкций из документов — выше качества и косметики.
- **Регрессия.** После правки — повторный прогон всех тест-кейсов, а не только упавшего; у изменённого навыка `version` +1.

## Рабочий процесс
- [ ] Определить объект: инструкция агента, SKILL.md, команда или пара «запрос + ответ».
- [ ] Пройти чек-лист своего типа из `Референсы/ЧЕК-ЛИСТЫ.md`.
- [ ] Для провала теста — найти симптом в `Референсы/ДИАГНОСТИКА.md`; если симптома нет — сформулировать гипотезу и способ её проверки одним тестом.
- [ ] Ранжировать проблемы: 🔴 критично → 🟡 качество → 🟢 косметика.
- [ ] Предложить правки «Поле → Было → Стало» и настройки, которые надо поменять.
- [ ] Предложить повторный прогон тест-кейсов и запись в журнал изменений.

## Шаблон вывода

**Оценка:** <N из M пунктов чек-листа>. **Главная проблема:** <одна фраза>.

| № | Важность | Проблема | Где | Причина |
|---|---|---|---|---|

**Правки**
- <Поле> → Было: «…» → Стало: «…»

**Настройки** (если причина не в тексте): <что и где поменять>.

**Повторный тест:** <какие тест-кейсы прогнать>; `version` навыка: <было → стало>.

## Проверка качества
- [ ] Отделены причины в тексте от причин в настройках.
- [ ] Каждая правка цитирует исходный текст («Было») дословно.
- [ ] Критичные проблемы идут первыми.
- [ ] Правки не противоречат стандарту платформы (агент-оркестратор, команды не в шагах агента, запись через подтверждение).
- [ ] Указано, какие тесты прогнать повторно.

## Ресурсы навыка
- `Референсы/ЧЕК-ЛИСТЫ.md` — чек-листы агента, навыка и команды.
- `Референсы/ДИАГНОСТИКА.md` — симптомы, причины, правки и антипаттерны.

Подгружай файл из `Референсы/` только когда он нужен для текущего шага.
