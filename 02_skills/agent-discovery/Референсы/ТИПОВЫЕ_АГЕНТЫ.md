# Типовые роли агентов

Каркасы для частых процессов. Берите ближайший и адаптируйте: навыки — это кандидаты, а не обязательный состав.

## 1. Аналитик документов
Проверка договоров, поиск несостыковок, сверка с регламентом, ответы по пакету документов.

| Фаза | Навык (slug) | Результат |
|---|---|---|
| Проверка | Проверка документа по чек-листу (document-check) | Таблица замечаний: пункт, цитата до 30 слов, риск 🔴🟡🟢, рекомендация |
| Сравнение | Сверка версий документа (document-diff) | Таблица расхождений между версиями |
| Ответы | Ответы по пакету документов (document-qa) | Ответ с цитатой и указанием файла и раздела |

- Контур: только загруженные файлы и документы пространства.
- Риски: выдуманные пункты и цитаты, пропущенные файлы. Правило: «Если файл не прочитан — назови его».
- Системные навыки: «Работа с Word (.docx)», «Работа с PDF», «Полнотекстовый поиск».

## 2. Оператор CRM или учётной системы
Заявки из почты → лиды; заказы → склад; записи клиентов.

| Фаза | Навык | Результат |
|---|---|---|
| Разбор входящих | Разбор входящих заявок (lead-intake) | Таблица заявок с полями и признаком «новый / существующий» |
| Ответ | Ответ на заявку клиента (lead-reply) | Черновик ответа до 120 слов |
| Запись | Создание записей по подтверждению (crm-write) | Созданные записи с ID из ответа системы |

- Режимы: поиск и чтение — «Включен»; создание — «Требует подтверждения»; изменение и удаление — «Отключен».
- Риски: дубли, запись без подтверждения, выдуманные поля («не указано» вместо догадки).

## 3. Мониторинг и сводки по расписанию
Почта, обращения, сделки, отзывы за период.

| Фаза | Навык | Результат |
|---|---|---|
| Сбор | Сводка за период (period-digest) | Сгруппированные события с приоритетом 🔴🟡🟢 |
| Реакция | Черновики ответов (reply-drafting) | Черновики без отправки |

- Обязателен «Режим по расписанию»: без вопросов, период по умолчанию — с прошлого запуска, но не больше 24 часов.
- Признаки важности задаются явно: отправители, слова «срочно», «претензия», суммы больше N.

## 4. Отчёт по данным
Продажи по менеджерам, план-факт, остатки, воронка.

| Фаза | Навык | Результат |
|---|---|---|
| Качество данных | Проверка выгрузки (data-quality-check) | `data_quality`: строк, период, пропуски, дубли |
| Расчёт | Расчёт метрик (metrics-calc) | Метрики по формулам через `python_run` |
| Выводы | Управленческая интерпретация (metrics-insights) | Вердикт → таблица с Δ% → точки внимания → рекомендации |

- Формулы — явные: «Конверсия = сделки / лиды × 100 %, 1 знак после запятой».
- Инвариант: модель не меняет посчитанные числа; знаменатели и допущения явные.

## 5. Исследователь
Справка о компании, обзор поставщиков или конкурентов, мониторинг рынка.

| Фаза | Навык | Результат |
|---|---|---|
| Стратегия | Стратегия поиска (search-strategy) | `стратегия_поиска.json`: контекст, границы, запросы, исключаемые источники |
| Поиск | Поиск и отбор (search-run) | Список с источником у каждого пункта |
| Отчёт | Сводка исследования (research-report) | Таблица в чате → файл после подтверждения |

- Контур: «плюс веб-поиск». Каждый факт — с URL и тем, что он подтверждает; без источника не включать.
- Исключать маркетплейсы и доски объявлений, если нужны первоисточники.

## 6. HR и рекрутинг
Скрининг резюме, подготовка к интервью.

| Фаза | Навык | Результат |
|---|---|---|
| Скрининг | Скрининг резюме (resume-screening) | Оценка по критериям вакансии с цитатами, red flags, ранжирование |
| Интервью | Вопросы для интервью (interview-questions) | Вопросы по пробелам кандидата |

- Персональные данные: минимизация; не учитывать пол, возраст, национальность, семейное положение, фото.
- Решение о кандидате — за человеком.

## 7. Ассистент по базе знаний
Ответы сотрудникам по регламентам пространства.

| Фаза | Навык | Результат |
|---|---|---|
| Ответ | Ответ по базе знаний (kb-answer) | Ответ + цитата + название документа |
| Пробелы | Журнал вопросов без ответа (kb-gaps) | Список вопросов, которых нет в базе |

- Контур: только документы пространства («Знания пространства», «Полнотекстовый поиск»). «Нет в документах — нет ответа».
