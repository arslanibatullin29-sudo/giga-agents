# Шаблон команды GigaCowork

Команда — короткая точка входа: логика живёт в навыке, команда только запускает его с параметрами.

| Поле | Правило | Пример |
|---|---|---|
| Имя команды | Глагол в инфинитиве + объект | Проверить договор поставки |
| Описание | «Запускает … / Собирает … / Готовит …», одна строка | Запускает проверку договора по чек-листу юристов |
| Инструкции | 1–2 предложения в повелительном наклонении; 1–3 аргумента; ожидаемый формат результата | Проверь договор ${файл_договора} по чек-листу: таблица замечаний с риском и рекомендацией, затем вердикт «подписывать / доработать». |
| Аргументы | Понятные имена через `${…}`; появляются в поле «Аргументы» | файл_договора |

Правила:
- Не больше 3 аргументов. Длинный текст (инструкцию, переписку) лучше приложить файлом: «если вместо текста указано «в файле» — возьми из приложенного файла».
- В инструкции указывай формат результата — так ответы на одну команду будут похожи.
- Если недостающее можно уточнить — так и напиши: «недостающие детали уточни вопросами».
- Команду добавляют агенту; вызывает её пользователь через «/». Агент сам команды не запускает, а в регулярных задачах команды недоступны.

Примеры формулировок:
- «Подготовь протокол встречи по записи ${файл_записи}: решения, задачи с ответственными и сроками, открытые вопросы; недостающее уточни вопросами.»
- «Сравни коммерческие предложения из ${файлы_кп} по критериям ${критерии}: сводная таблица, рейтинг и риски по каждому поставщику.»
