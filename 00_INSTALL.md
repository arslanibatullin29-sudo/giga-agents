# Как перенести «Архитектора агентов» в GigaCowork

Версия комплекта: 4 (сверено с документацией GigaCowork 26.9.1). Время: 20–30 минут.

## Что в комплекте

| Файл | Что это |
|---|---|
| `01_agent-instruction.md` | Текст для поля «Инструкция» агента — вставляется целиком |
| `02_skill-konstruktor-agentov.zip` | Навык целиком: `SKILL.md` + `example-passport.md` + `platform-checklist.md` |
| `02_skill-konstruktor-agentov/` | Те же три файла по отдельности — для ручного переноса |
| `03_commands-and-tests.md` | 4 команды и 8 тест-кейсов |
| `04_research.md` | Почему промпт устроен так, источники, что проверить |

Копируйте текст из `.md`-файлов, открытых в простом текстовом редакторе (Блокнот, VS Code, TextEdit в режиме «простой текст»). DOCX-версия — для чтения: Word может заменить кавычки и сломать разметку.

## Порядок переноса

**Навык → Команды → Коннектор (по желанию) → Агент → Тест → Работа.**

Порядок важен: в форме агента навыки и команды выбираются из уже созданных, а в задаче с агентом доступны только его навыки, команды и коннекторы.

## Шаг 0. Проверьте формат навыка (2 минуты, по желанию)

Откройте любой навык в разделе «Навыки» → «⋮» → «Скачать (zip)» и посмотрите, как устроен архив: `SKILL.md` в корне или внутри папки. Мой архив устроен так: `SKILL.md` и два файла лежат в корне. Если у платформы иначе — повторите её структуру или используйте ручной вариант из шага 1.

## Шаг 1. Навык «Конструктор агентов GigaCowork»

**Вариант А — загрузка файла**
1. Меню → «Навыки» → «Создать навык» → «Загрузить файл навыка».
2. Выберите `02_skill-konstruktor-agentov.zip` → «Далее». Категория в файле не указана: если платформа предложит её выбрать — выберите ближайшую по смыслу. Если появится ошибка «Выберите категорию из списка» или архив не примется по другой причине — переходите к варианту Б: он работает всегда.
3. Откройте навык: слева в дереве файлов должны быть `SKILL.md`, `example-passport.md`, `platform-checklist.md`.

**Вариант Б — вручную**
1. «Навыки» → «Создать навык» → «Написать инструкцию навыка».
2. Заполните поля в визуальном редакторе (так категорию можно выбрать из списка):
   - **Имя навыка:** `Конструктор агентов GigaCowork`
   - **Когда применять:** текст из строки `description:` без кавычек
   - **Категория:** выберите из выпадающего списка ближайшую по смыслу (автоматизация, продуктивность, работа с документами — что есть в списке)
   - **Инструкции:** всё, что ниже второй строки `---`
3. Сохраните.
4. Откройте навык → в списке файлов нажмите «+» → «Загрузить файл» → `example-passport.md`. Повторите для `platform-checklist.md`.

**Проверка:** навык виден в «Навыки» → фильтр «Личные», в дереве три файла.

## Шаг 2. Четыре команды

Для каждой: меню → «Команды» → «Создать команду» → заполнить «Имя команды», «Описание», «Инструкции» из файла `03_commands-and-tests.md`. Переменные `${…}` копируйте как есть.

| Имя команды | Для чего |
|---|---|
| Спроектируй агента | Интервью и паспорт нового агента |
| Проверь агента | Аудит инструкции существующего агента |
| Улучши агента по тесту | Точечная правка по результату теста |
| Разложи процесс на агентов | Карта агентов, навыков и команд для процесса |

**Проверка:** «Команды» → «Личные» — 4 карточки.

## Шаг 3. Коннектор «Веб-поиск» (по желанию)

Нужен, чтобы Архитектор изучал специфику отрасли. «Коннекторы» → «Веб-поиск» → «Войти в аккаунт» (если коннектор уже авторизован администратором, кнопки не будет — это нормально).

Регламенты, по которым проектируется агент, проще прикладывать файлами к задаче, чем подключать хранилища.

## Шаг 4. Агент «Архитектор агентов»

Меню → «Агенты» → «Создать агента»:

**Название**
```
Архитектор агентов
```

**Описание**
```
Проектирует ИИ-агентов под ваш процесс: задаёт вопросы, выбирает архитектуру и выдаёт паспорт агента — тексты для всех полей, навыки, команды, права коннекторов и тест-кейсы.
```

**Инструкция** — всё содержимое `01_agent-instruction.md`.

**Навыки** — системные оставьте все (так стоит по умолчанию: через них агент читает файлы и ищет по документам; не исключено, что через них же работает создание навыков из чата) и добавьте кнопкой «+» навык «Конструктор агентов GigaCowork».

**Команды** — кнопкой «+» добавьте все 4 команды из шага 2.

**Коннекторы** — «Веб-поиск», если подключили его на шаге 3.

Сохраните.

**Если инструкция не помещается в поле:** удалите из неё разделы «Что нужно знать о платформе» и «Чек-лист самопроверки» — их копия лежит в навыке (`platform-checklist.md`), и агент прочитает её оттуда.

## Шаг 5. Тест (10–15 минут)

«Агенты» → карточка «Архитектор агентов» → «⋮» → «Редактировать». Справа — тестовый чат. Прогоните 8 тест-кейсов из `03_commands-and-tests.md` и сравните поведение с колонкой «Ожидаемое поведение».

Если что-то не так — правьте инструкцию в этом же окне и повторяйте тест. Типовые причины — в таблице «Частые проблемы» ниже.

## Шаг 6. Как пользоваться

1. «Новая задача» → «Добавить агента» (кнопка `@` в поле ввода) → «Архитектор агентов». Или «Использовать» на карточке агента.
2. Приложите кнопкой «+» регламент, чек-лист или пример хорошего результата, если они есть.
3. Опишите процесс обычными словами или наберите `/` → «Спроектируй агента».
4. Ответьте на вопросы (можно «по умолчанию»).
5. Получите паспорт и **скачайте его** из панели «Документы»: при удалении задачи файлы удаляются.
6. Согласитесь создать навыки и команды прямо в чате. Затем откройте их в разделах «Навыки» и «Команды» и сверьте с паспортом: система может дописать текст по-своему. Расхождения поправьте через «Редактировать».

Один агент — одна задача: все запросы в задаче связаны, поэтому следующего агента проектируйте в новой задаче.

## Шаг 7. Как по паспорту создать нового агента

1. **Коннекторы.** «Коннекторы» → нужный коннектор → «Войти в аккаунт» → блок «Инструменты» → режимы по таблице раздела 6 паспорта. Режимы действуют во всех ваших задачах, не только в этом агенте. Служебные инструменты подключения не отключайте.
2. **Навыки** из раздела 4 — если не создали их из чата.
3. **Команды** из раздела 5.
4. **Агент.** «Агенты» → «Создать агента» → поля из разделов 1–3; добавьте навыки, команды и коннекторы из паспорта. Что не добавлено в форму, в задаче с агентом недоступно.
5. **Тест.** Тест-кейсы из раздела 8 — в тестовом чате агента. Ошибки → новая задача с Архитектором → `/Улучши агента по тесту`.
6. **Регулярная задача** (если есть раздел 7). «Регулярные задачи» → «Запланировать задачу» → поля из паспорта. Для «Каждый день» у всех времён должны быть одинаковые минуты (9:15, 13:15, 18:15). Если в форме можно выбрать агента — выберите. Проверьте сразу: карточка задачи → «⋮» → «Запустить задачу», результат — в разделе «История».

## Шаг 8. Перенос в пространство (чтобы пользовалась команда)

Агентов пространства создаёт только владелец пространства. Личный агент в задачах пространства недоступен — нужен отдельный агент пространства.

1. Пространство → вкладка «Навыки» → «Добавить навыки» → в поле «Расположение» выберите личные → «Добавить» у «Конструктор агентов GigaCowork».
2. Вкладка «Команды» → «Управление командами» → «Расположение»: личные → «Копировать» у каждой из 4 команд.
3. Вкладка «Агенты» → «Создать агента» → те же поля, что в шаге 4; навыки и команды выбирайте из пространства.
4. Каждый участник сам авторизует свои коннекторы (например, «Веб-поиск»).

Копии в пространстве не связаны с личными оригиналами: после обновления личного навыка или команды скопируйте их в пространство заново.

## Частые проблемы

| Симптом | Причина | Что сделать |
|---|---|---|
| Архив навыка не загружается | Платформа ждёт другую структуру | Шаг 0 или ручной вариант Б |
| Инструкция не помещается в поле | Лимит длины | Удалить два раздела (см. шаг 4) |
| В форме агента нет навыка или команд | Не созданы или созданы только в пространстве | Создать личные (шаги 1–2) |
| Архитектор отвечает без шаблона паспорта и примера | Навык не добавлен агенту | Добавить навык в форму агента |
| Команд нет в меню `/` в задаче с Архитектором | Команды не добавлены агенту | Добавить в форму агента |
| Не получается создать навык из чата | Возможно, у агента убраны системные навыки | Вернуть системные навыки в форме агента; если не помогло — создать навык вручную по паспорту |
| Архитектор не видит регламент | Файл не приложен к этой задаче или тестовому чату | Приложить файл кнопкой «+» |
| Паспорт пропал | Задача удалена вместе с файлами | Скачивать паспорт сразу или добавлять в пространство |
