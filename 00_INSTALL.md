# Как установить «Архитектора агентов» в GigaCowork

Версия комплекта: 5. Время: 20–30 минут.

## Что в комплекте

| Файл | Что это |
|---|---|
| `01_agent-instruction.md` | Текст для поля «Инструкция» агента — вставляется целиком |
| `02_skills/agent-discovery.zip` | Навык «Интервью и выбор архитектуры агента» |
| `02_skills/agent-passport.zip` | Навык «Сборка паспорта агента» |
| `02_skills/skill-design.zip` | Навык «Проектирование навыка GigaCowork» |
| `02_skills/agent-review.zip` | Навык «Аудит и доработка агента» |
| `02_skills/<навык>/` | Те же навыки файлами — для ручного создания |
| `03_commands-and-tests.md` | 4 команды и 10 тест-кейсов |

Копируйте текст из `.md`-файлов, открытых в простом текстовом редакторе, а не из DOCX.

## Порядок

**Навыки → Команды → Агент → Тест → Работа.** В форме агента навыки и команды выбираются из уже созданных, а в задаче с агентом доступны только его навыки, команды и коннекторы.

Если у вас уже есть навык «Конструктор агентов GigaCowork» из прошлой версии — удалите его: его заменили четыре навыка.

## Шаг 1. Четыре навыка

Для каждого архива: «Навыки» → «Создать навык» → «Загрузить файл навыка» → архив → «Далее».

**Про категорию.** В архивах стоит `category: sales` — единственное значение, которое точно есть в списке категорий платформы. После загрузки откройте навык и выберите подходящую категорию в редакторе. Если пришлёте список категорий из формы навыка — поставлю правильную в файлы.

Если архив не принимается:
1. «Создать навык» → «Написать инструкцию навыка».
2. Заполните поля: **Имя навыка** — строка `name`, **Когда применять** — строка `description` без кавычек, **Категория** — из списка, **Инструкции** — всё ниже второй строки `---` в `SKILL.md`.
3. Сохраните, откройте навык и в дереве файлов создайте папку `Референсы` с файлами из папки навыка (кнопка «+» → «Создать папку» / «Загрузить файл»).

**Проверка:** в «Навыки» → «Личные» четыре навыка, у каждого папка `Референсы`.

## Шаг 2. Четыре команды

«Команды» → «Создать команду» — по таблице из `03_commands-and-tests.md`: имя, описание, инструкции. `${…}` копируйте как есть.

## Шаг 3. Агент

«Агенты» → «Создать агента»:

**Название**
```
Архитектор агентов
```

**Описание**
```
Проектирует ИИ-агентов под ваш процесс — от интервью до паспорта агента, навыков с архивами для загрузки, команд и тест-кейсов.
```

**Инструкция** — всё содержимое `01_agent-instruction.md`.

**Навыки** — системные оставьте по умолчанию и добавьте четыре: «Интервью и выбор архитектуры агента», «Сборка паспорта агента», «Проектирование навыка GigaCowork», «Аудит и доработка агента».

**Команды** — все четыре из шага 2.

**Коннекторы** — по желанию «Веб-поиск», чтобы изучать специфику отрасли.

## Шаг 4. Тест

Карточка агента → «⋮» → «Редактировать» → тестовый чат справа. Прогоните 10 тест-кейсов из `03_commands-and-tests.md`. Порог — 9 из 10.

## Шаг 5. Работа

1. «Новая задача» → `@` → «Архитектор агентов».
2. Приложите регламент, чек-лист или пример хорошего результата.
3. Опишите процесс или наберите `/` → «Спроектировать агента».
4. Ответьте на вопросы брифа (можно «по умолчанию») и подтвердите решение.
5. Получите паспорт и навыки. Если Архитектор собрал архивы навыков в `/session`, скачайте их из панели «Документы» и загрузите через «Загрузить файл навыка». Если нет — создайте навыки по текстам из чата.
6. Скачайте паспорт: при удалении задачи её файлы удаляются.

Один агент — одна задача: следующего агента проектируйте в новой задаче.

## Шаг 6. Как по паспорту создать нового агента

1. **Коннекторы:** «Войти в аккаунт», режимы инструментов по таблице паспорта. Режимы действуют во всех ваших задачах.
2. **Навыки:** загрузить архивы или создать по текстам.
3. **Команды.**
4. **Агент:** поля 1–3 паспорта; добавить навыки, команды, коннекторы.
5. **Тест:** тест-кейсы паспорта; ошибки → новая задача с Архитектором → `/Разобрать провал теста`.
6. **Регулярная задача:** у «Каждый день» одинаковые минуты; проверьте через «⋮ → Запустить задачу».

## Шаг 7. Для команды (пространство)

Агентов пространства создаёт только владелец; личный агент в задачах пространства недоступен.
1. Вкладка «Навыки» → «Добавить навыки» → «Расположение»: личные → добавить четыре навыка.
2. Вкладка «Команды» → «Управление командами» → «Расположение»: личные → «Копировать» четыре команды.
3. Вкладка «Агенты» → «Создать агента» → те же поля; навыки и команды — из пространства.

Копии не связаны с оригиналами: после обновления навыков скопируйте их заново.

## Частые проблемы

| Симптом | Что сделать |
|---|---|
| «Категория должна состоять из строчных букв…» | `category` латиницей, из списка платформы |
| «Выберите категорию из списка» | Значения нет в списке — выберите категорию в форме навыка |
| Искажённые русские имена файлов | Используйте архивы из этого комплекта или собранные Архитектором — они с пометкой UTF-8 |
| Инструкция не помещается в поле | Удалите раздел «Что важно знать о платформе» — полный справочник есть в навыке «Сборка паспорта агента» |
| Архитектор не задаёт вопросов брифа и сразу пишет паспорт | Навык интервью не добавлен агенту |
| Архитектор не может собрать архив | `python_run` или `/session` недоступны в вашей версии — навыки создаются вручную по текстам |
| Команд нет в меню `/` в задаче с Архитектором | Команды не добавлены агенту |
